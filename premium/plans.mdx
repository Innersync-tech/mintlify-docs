## How to subscribe

<Steps>
  <Step title="Visit the pricing page">
    Go to [pricing.alphapy.innersync.tech](https://pricing.alphapy.innersync.tech). If you have an early bird code, you can enter it there to see discounted pricing.
  </Step>
  <Step title="Choose a plan and complete checkout">
    Select Monthly, Annual, or Lifetime and complete checkout. Payments are processed securely by **Mollie B.V.** All prices are in Euro (€).
  </Step>
  <Step title="Activate in your Discord server">
    After checkout, open Discord and run `/premium` in the server where you want to activate premium. This links your subscription to that server.
  </Step>
  <Step title="Connect the Innersync App">
    Run `/link` in your server to connect your Innersync account. This is required for personal agents and enables consent-gated reflection sharing.
  </Step>
  <Step title="Confirm your premium status">
    Run `/my_premium` to verify your subscription is active and see your expiry date (or "Lifetime" for lifetime subscribers).
  </Step>
</Steps>

## One server per subscription

Premium applies to **one Discord server at a time**. After subscribing, the first server where you run `/premium` becomes your active premium server.

If you want to move your premium to a different server — for example, because you changed communities — run `/premium_transfer` in the new server. Your premium will move there immediately.

<Note>
  If `/my_premium` shows "You have Premium but haven't chosen a server yet," run `/premium` in the server you want to activate it on. If it shows "Your Premium is active in another server," run `/premium_transfer` in the new server to move it.
</Note>
