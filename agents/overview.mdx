Alphapy Agents bring a new kind of AI experience to your Discord server — a personal reflection assistant that knows your growth journey. Unlike a one-off chat command, an agent maintains context about your past check-ins, your goals, and the patterns in your reflections across multiple conversations over time. Every session is a private, continuous dialogue designed to help you notice what's working, challenge what isn't, and move forward with intention.

## How agents work

Alphapy's reflection agent is built around four core principles:

**Memory across sessions.** Your agent remembers insights and patterns from your previous growth check-ins and past agent sessions. Over time it can surface recurring themes, flag progress, and ask sharper follow-up questions — because it already knows your context.

**Multi-turn conversations.** A single agent session can span as many exchanges as you need. Start a session, ask a question, then keep exploring with follow-up messages before wrapping up. You're not limited to one prompt and one reply.

**Privacy-first by design.** Agents only ever access reflections you have explicitly chosen to share. Your encrypted App journals are completely off-limits — the agent cannot read, request, or decrypt them. Only the reflections you opted to share through `/growthcheckin` are ever used as context.

**Powered by Grok AI.** Responses are generated by Grok using the shared reflections and growth data you've made available. The more consistently you check in and share, the richer the context your agent can draw from.

## Prerequisites

Before you can start an agent session, three things need to be in place:

1. **Link your Innersync account.** Run `/link` in Discord to connect your Discord identity to your Innersync account. This is required for agents to access your personal growth data. Without it, `/agent` commands will not work.

2. **Agents must be enabled in your server.** A server admin needs to run `/config agents toggle true` to turn on the agents feature for that guild. If you're unsure whether agents are active, run `/agent list` — if the command responds with available agents, you're good to go.

3. **Check available agents.** Run `/agent list` to see which agents are currently available. The reflection agent is the active agent right now, with more planned for the future.

## Usage limits

The number of sessions you can start each day depends on your plan. Note that `/agent continue` — used to add follow-up turns within an existing session — **does not count** toward your daily limit. Only `/agent start` is metered.

| Plan | `/agent start` per day |
|------|------------------------|
| Free | 10 |
| Monthly Premium | 25 |
| Annual Premium | Unlimited |
| Lifetime Premium | Unlimited |

<Note>
  If you reach your daily limit, you'll receive an ephemeral message with information about upgrading. Run `/premium` to compare plans and pricing.
</Note>
